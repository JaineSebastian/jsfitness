# JS FITNESS — Android App

**Dec 2023 – Apr 2024** · Baselios Poulose II Catholicos College, Illikkamukkada, Kerala

JS FITNESS: An Android App for Comprehensive Fitness Management.

An innovative Android application designed to revolutionize fitness management. JS FITNESS aims to provide users with a comprehensive platform for tracking, managing, and improving their fitness journey.

The app offers a range of features tailored to meet the diverse needs of individuals striving for better health and fitness. Users can create personalized profiles, set fitness goals, and access a database of exercises, workouts, and nutritional information. The app's intuitive interface allows for easy logging of daily activities, including workouts, meals, water intake, and sleep patterns.

JS FITNESS incorporates data analytics and AI-driven algorithms to generate personalized recommendations and insights based on user inputs. The app also fosters a supportive community environment by enabling users to connect with like-minded individuals, share achievements, and participate in challenges and group activities.

## Project structure

- `JSFitnessAnd/JSFitness/` — Android app (Java, Gradle / Android Studio project)
- `jsfitness/jsfitness/` — Python backend server (Flask-style app: `main.py`, `admin.py`, `trainer.py`, `user.py`, `public.py`) with MySQL database (`inmatedb.sql`)

## Skills

Android architecture and tools, Java, Python, MySQL
